MES TACHES - ACCES DEPUIS LE TELEPHONE
======================================

1. Double-cliquez sur "Demarrer Mes Taches.bat".
2. Laissez la fenetre noire ouverte.
3. Connectez le telephone au meme Wi-Fi que ce PC.
4. Ouvrez dans le navigateur du telephone l'adresse affichee ci-dessous :

   http://192.168.1.66:8765

L'adresse exacte est aussi affichee dans la fenetre noire au demarrage.
Elle peut changer si votre box attribue une nouvelle adresse au PC.

Connectez-vous avec le meme compte dans chaque navigateur. Les modifications
sont enregistrees dans Supabase et apparaissent automatiquement sur les autres
appareils en quelques secondes.

La version publiee sur GitHub Pages fonctionne aussi en 4G ou 5G et ne
necessite pas que le PC reste allume.
