MES TACHES - ACCES DEPUIS LE TELEPHONE
======================================

1. Double-cliquez sur "Demarrer Mes Taches.bat".
2. Laissez la fenetre noire ouverte.
3. Connectez le telephone au meme Wi-Fi que ce PC.
4. Ouvrez dans le navigateur du telephone l'adresse affichee ci-dessous :

   http://192.168.1.66:8765

L'adresse exacte est aussi affichee dans la fenetre noire au demarrage.
Elle peut changer si votre box attribue une nouvelle adresse au PC.

Connectez-vous avec le meme compte dans chaque navigateur. Les modifications
sont enregistrees dans Supabase et apparaissent automatiquement sur les autres
appareils en quelques secondes.

La version publiee sur GitHub Pages fonctionne aussi en 4G ou 5G et ne
necessite pas que le PC reste allume.

RETROPLANNING
=============
Lors de la creation d'une tache, le bouton "Date" ouvre directement un
calendrier. Cliquez sur un jour pour le choisir : aucune saisie de texte
ni confirmation supplementaire. "Sans date" retire la date avant creation.
Les taches Lycee, Perso et Actuelle apparaissent dans le retroplanning.

Glissez une tache du retroplanning sur un autre jour pour changer sa date.
Cliquez sur une tache ou son bouton de date pour ouvrir le meme calendrier,
notamment sur telephone
ou pour la deplacer vers un autre mois. Les changements sont synchronises
comme les autres modifications.

Les niveaux d'urgence et les descriptions ne sont plus affiches ni proposes
a la creation. Les anciennes donnees sont conservees en interne pour ne pas
perdre les dates existantes et rester compatible avec la synchronisation.

FOND ET COULEURS
===============
Le bouton "Fond & couleurs" propose quatre ambiances (Nuit, Ocean, Foret,
Prune). Les curseurs Rouge, Vert et Bleu reglent la balance des couleurs
en direct, avec un fond sombre pour garder le texte lisible.
Les couleurs sont conservees sur cet appareil apres rechargement.
"Reinitialiser" retablit l'ambiance Nuit.

L'option "Degrade de gauche a droite" permet de choisir independamment
la couleur gauche et la couleur droite. Les cartes restent sombres pour
garder le texte lisible. Le degrade est aussi conserve sur cet appareil.

MODIFICATION ET INSTALLATION
===========================
Cliquez sur le titre d'une tache (ou d'un objectif) pour le modifier.
Ses dates, son etat et son epinglage sont conserves.

Le bouton "Installer l'app" propose l'installation quand le navigateur
la permet. Sur Android : Chrome > menu > Installer l'application.
Sur iPhone : Safari > Partager > Sur l'ecran d'accueil.
Utilisez la version HTTPS GitHub Pages, pas l'adresse Wi-Fi HTTP.
Apres une premiere ouverture connectee, l'interface est mise en cache.
Les changements hors ligne restent sur cet appareil jusqu'au retour
de la connexion. L'installation n'est pas une publication App Store.
